-- Como voltar para uma versão anterior do git
Pelo Terminal (mais seguro):
1. Abra o terminal integrado no VS Code (Ctrl + ').
2. Use o comando abaixo para ver o ID do commit (hash) para o qual você quer voltar:
git log --oneline
3. Para voltar para um commit específico, use:
git reset --hard ID_DO_COMMIT
(Substitua ID_DO_COMMIT pelos primeiros 7 caracteres do ID que apareceu no comando anterior).

Precisa para rodar no windows GTK

O WeasyPrint precisa de bibliotecas GTK para funcionar no Windows. Você instalou o pacote Python, 
mas faltam as dependências de sistema.
Solução para Windows
Instalar GTK (Recomendado)
Baixe o GTK para Windows:
1. Acesse: https://github.com/tschoonj/GTK-for-Windows-Runtime-Environment-Installer/releases
2. Baixe o arquivo gtk3-runtime-3.24.31-2024-01-13-ts-win64.exe (ou versão mais recente)
3. Instale o GTK:
4. Execute o instalador
5. Aceite os termos
6. Durante a instalação, marque a opção "Add GTK to PATH" (ou similar)
7. Complete a instalação



Nota importante pra depois

Isso é um problema estrutural que vai voltar a te morder: .env.production deveria conter o valor de 
produção de verdade (algo como https://api.flowheart.com), não um valor de teste local. Quando você 
for realmente publicar o app, alguém vai precisar lembrar de trocar esse valor de novo — e nesse meio 
tempo, qualquer teste local com npm run build vai continuar quebrando por engano.

Sugestão mais robusta: para testes locais no emulador, use npm run dev (modo desenvolvimento, que 
lê .env.development/.env) ao invés de npm run build + preview, deixando o .env.production intocado, 
reservado só pra quando for de fato pra produção.
Pode fazer direto no PowerShell, sem abrir editor:
powershell
(Get-Content .env.production) -replace 'VITE_API_URL=http://localhost:8000', 
'VITE_API_URL=http://10.0.2.2:8000' | Set-Content .env.production
Depois confirme:
powershell
Get-Content .env.production

(Get-Content .env.production) -replace 'VITE_API_URL=http://10.0.2.2:8000', 
'VITE_API_URL=http://localhost:8000' | Set-Content .env.production
